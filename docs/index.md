# Documentation

Use these guides according to what you are doing:

- [Getting started](getting-started.md): install, validate, run, inspect, and
  export a first inversion.
- [Configuration reference](configuration.md): every YAML section, option,
  default, constraint, and operational consequence.
- [Problem integration](problem-integration.md): implement solver, posterior,
  and initial-data factories in an independent package.
- [Architecture and algorithms](architecture.md): coordinator lifecycle,
  persistence, surrogate training, HMC, and active selection.
- [Operations and troubleshooting](operations.md): run directories, budgets,
  restart behavior, failures, and common MPI issues.
- [Examples](examples.md): equations, intended lessons, and run
  commands for all bundled examples.
- [Python and CLI API](api.md): supported imports, callback data classes, and
  command behavior.
- [Development and release](development.md): tests, quality gates, packaging,
  compatibility, and the release checklist.

The root [README](../README.md) is the concise project overview.
